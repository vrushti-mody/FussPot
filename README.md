# FussPot

An informational website for Fuss Pot, a fashion and home décor boutique in Khar West, Mumbai.

## Run locally

From this directory, start a static server:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.

## Contents

- `index.html` — the main site
- `styles.css` and `script.js` — styling and interactions
- `privacy.html`, `terms.html`, and `cookies.html` — informational legal pages
- `public/images/` — locally hosted editorial images
